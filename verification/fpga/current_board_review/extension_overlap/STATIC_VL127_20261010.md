## Conclusion

The real reduced reproducer is **seed0/op2/VL127/mask-mode0/cap128**, executing
`vzext.vf2 v24,v25,v0.t` at e16/m2, VLEN1024, tu/mu, vstart0. Mask mode0 is
**all ones**, not all off. It is available as pinned original-source single-case
files; there is no need to substitute the passing generic VL2 fixture.

No extension-specific repair was found in the inspected current dispatcher or
operand requester. The strongest current static candidate is a missed overlap
classification: extension leaves destination SEW equal to CSR SEW, whereas the
relevant widening-overlap/snapshot classifiers require destination SEW to be
greater. Conditional on maintenance requests completing, this can alternate
v25's stored EEW between 8 and 16 before the target is ever accepted. This is
a falsifiable hypothesis, **not newly measured cycle proof or closure of all
42 records**. A blocked first maintenance request remains a distinct alternative.

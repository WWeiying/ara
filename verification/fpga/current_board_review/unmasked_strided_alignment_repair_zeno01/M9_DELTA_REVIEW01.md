# M9 AddrGen Delta Review

Decision: **NO_STATIC_BLOCKER_M9_ADDRGEN_DELTA_ONLY**.

Reviewed current AddrGen SHA `3736b64136ebbf5629dadb0037457279f9bb91307356c468c9677d321c8c51c5` against frozen M8 `1cc40e2669e310ae25e23f5c9ee1f7ee493dc1ac990d70d8b8122f47e93742b2`. VLDU, VSTU, main sequencer and dispatcher still match M8 byte-for-byte.

- Single-driver context: vstart_o is assigned only in addr_generation always_comb, defaulting to internal q and overriding only the initial effective-start fault. Internal q is written only by its original reset/update always_ff; d remains in the AXI generation block. No second procedural writer or missing combinational default.
- Effective start: initial comparison/tval use vaddr_start. On this same combinational ack, vstart_o uses held pe_req_q.vstart, avoiding the previously identified registered-index lag. Failed initial request never asserts addrgen_req_valid, so no new AXI/MMU acquisition.
- Defer scope: held lookahead_len_q, op, vm, stride and EEW are captured with the same accepted request. Only multi-element vm1 VLSE/VSSE with nonmultiple-EEW increments takes additional WAIT. The predicate is based on original remaining length, not decremented AXI len, so it cannot disappear before fault delivery. Final-completion eligibility matches the added wait class.
- Ordered fault/context: existing nonburst active-address rejection now covers vm1. One descriptor push and exception_d/index_d update occur together; the next edge makes exception_q/index_q available to WAIT's ack. AXI state returns IDLE and front WAIT supplies no new addrgen request, avoiding repeat markers. All WAIT errors in this path originate from queued local/MMU exception markers; early-illegal is suppressed without suppressing the architectural exception.
- FIFO/backpressure: local fault and start_req both require capacity and the existing channel-order guard. A full/blocked FIFO produces neither a fault ack nor a fall-through request. A local rejection with capacity needs no AR/AW-ready handshake; it can queue its marker while the real good prefix remains ahead. Consumer prefix/partial-result/WLAST/B-drain gates are unchanged.
- MMU priority: the local fault branch precedes start_req. It never enters the nested translation_req assignment; mmu_req defaults0. Initial effective-start rejection likewise never starts AXI generation. The pre-existing indexed address-valid MMU guard is untouched. No locally rejected address can provisionally acquire then abandon the MMU through the new path.
- ACK/consumer timing: unsafe front enters WAIT before later fault generation, forwards the latched exception instead of a success ack, and keeps the same owner. The main sequencer's existing captured-ack/exception and load-done/store-B requirements are unchanged. No duplicate early-illegal bypasses the ordered marker.
- Normal-path cycle structure: vm1 unit bursts, stride0, positive/negative EEW multiples and aligned remaining-one strides retain the old front-state/ack and AXI branches. Masked/indexed paths retain their original classification. No new pipeline stage or unconditional strided wait was inserted. This supports cycle-equivalence intent, not measured cycles or synthesis timing closure.

Residual verification: compile/single-driver elaboration, repaired prefix/precise context under backpressure, resident-MMU non-acquisition for local rejects, store B drain, and exact aligned-control cycles require bounded repair evidence. This reviewer ran no simulator, parsed no CSV, changed no production source and did not touch M8 image or active jobs.

## Measured Root Cause

Original trial 9 is e32m8 VL65 VFWREDUSUM, seed FP64 2.0, only source indices
1 (+Inf) and 33 (-Inf) active. They occupy different partial sums in lane 1.
At cycle 34 the final intra-lane merge accepts B=`7ff0000000000000`,
C=`fff0000000000000`, source-enable=0, source-count=16, work-count=1,
control=0, predicate=0. Before: issue_be/tag=0. At cycle 39 raw FMA NV=`10`
is collapsed/gated to `00`; result is the correct `7ff8000000000000`.
After: issue_be=`ff`, tag=`0f`, raw/collapsed/gated NV=`10`. Lane 1 publishes
NV at cycle 64, the same cycle as local done. Completion remains 72 cycles,
including the bench's drain window.

Independent discriminators in the identical 80-case traces:

| Case | Lane / phase | Accept / output cycle | Before | After |
| --- | --- | --- | --- | --- |
| interlane_opposite | 3 / inter RX | 356 / 361 | raw NV lost, tag 0 | NV retained, tag 0f |
| remote_active_snan_seed | 0 / first intra | 541 / 546 | seed quieted under predicate 0, NV lost | NV retained until global activity known |
| simd_fp32 | 0 / SIMD | 783 / 787 | raw NV lost, tag 0 | low-slot NV retained, issue_be 0f |
| simd_fp16_upper_slot | 0 / first SIMD fold | 840 / 843 | physical slot 1 NV lost | issue_be 0f/tag 03 retains slot 1 NV |

For the FP16 discriminator, raw low-slot status is zero but packed raw status
is `00200` (NV in physical slot 1). This disproves a one-slot-only SIMD fix.
The next FP16 fold uses issue_be `03`.

The source predicate was incorrectly reused as an arithmetic exception mask
for intra-lane partials, while inter-lane/SIMD phases inherited zero issue_be.
Local-activity gating also loses seed sNaN exceptions when only a remote lane
contributes. Unconditional early publication would instead break all-masked
seed copies.

## Repair And Timing

Internal arithmetic masks enable predicate/tail-neutralized operands, including
the seed and partial sums. Pure neutral injection remains masked. Source
activity is tracked separately with the original predicate and true source
count, so mask expansion cannot turn an empty reduction into an active one.
Each lane accumulates unordered flags and publishes them on transition from
LN0_REDUCTION_COMMIT or completed SIMD_REDUCTION into MFPU_WAIT, gated by
global activity. Pending flags clear at publication. All-masked seed bits and
zero flags are preserved, including min/max and sNaNs.

Static timing/ownership review:

- The reduction retains its issue/processing queue entry through MFPU_WAIT;
  queued ordinary instructions cannot contribute to its pending accumulator.
- The registered publication is present no later than VMFPU done. The bench
  rejects late reduction flag pulses and checks exactly one per lane.
- Lane sequencer registers VMFPU done before forwarding it to ara_sequencer.
  Global running/idle is registered again. Dispatcher forwards flags directly.
- Existing CVA6 acc_dispatcher waits on backend busy and fflags_valid before
  FP CSR accesses; csr_regfile accrues accelerator flags at that clock edge.
- The checker reproduces dispatcher's actual contract: OR all lane flag data
  whenever any lane asserts flag-valid, not an OR of individually valid lanes.
- Queued finite VFADD after NV and after an all-masked sNaN reduction both pass;
  queued invalid VFADD produces NV; a subsequent finite reduction stays clear.
  No nonzero invalid flag bus was observed, so the ordinary flag path is not
  changed speculatively.

Real sequencer/SLDU epoch timing and immediate CSR reads still require the
parent's full-ELF replay. The unit does not instantiate those components.

## Fixed fixture contract

The compiled logic is unmodified `hardware/src/vlsu/addrgen.sv`, its real
FIFO, spill register, LZC and package/header dependencies. PE/exception/AXI
types use the repository typedefs. CVA6 configuration is expanded through
the repository `build_config_pkg::build_config()` with the sv39 user config;
XLEN=64, address-interface VLEN=64, PLEN=56. Sv39's page-table format is not
the address-interface width. Ara vector length is separately VLEN=1024.

All three cases use NrLanes=4, AXI data width256, VLE, id3, vm0, e16/m1,
VL8, vstart0, FOF0, aligned virtual base `0x40001000`. Mask owner is id3,
first_element=0, all lane mask-valid bits are1 from before request admission.
All-off payload is zero; active control has expanded element0 byte enables
`mask_word[0][1:0]=11`. No predicates or DUT state are forced/deposited.

ARREADY/AWREADY are1, descriptor queue starts empty, and scalar-store pending
is0. The MMU model observes the first real `mmu_req_o`, then returns exactly
one response three sampled cycles later. It holds no previous transaction
or unsolicited exception. Fault responses have valid1/cause13/tval=target;
success maps the same virtual address to `0x80010000`.

The sink pops each descriptor only when valid. The abstract sequencer clears
the running ID after both AddrGen ack and descriptor consumption; the log
labels this `MODEL_RELEASE`, not real VLDU completion. Consequently the
eventual idle check certifies only local quiescence under that sink contract.

## Measured causal order

CSV/log cycles are pre-NBA samples at rising edges of a 10ns clock. Reset is
released at40ns: cycle1=45ns, cycle3=65ns, cycle6=95ns, cycle7=105ns.

| Event | alloff_fault | active_fault | alloff_valid |
|---|---:|---:|---:|
| PE request accepted | 1 | 1 | 1 |
| First real MMU request | 3 | 3 | 3 |
| Request remains high | 3,4,5 | 3,4,5 | 3,4,5 |
| MMU response | 6, cause13 | 6, cause13 | 6, no exception |
| Descriptor push | 6, exception | 6, exception | 6, normal |
| AXI AR handshake | none | none | 6 |
| AddrGen ack | 7, cause13 | 7, cause13 | 6, no exception |
| Descriptor pop | 7 | 7 | 7 |

Each case has exactly one accepted PE request, one translation episode, one
MMU response, one push/pop and one ack. Request levels in cycles3-5 are one
outstanding episode, not three translations. At response cycle6
`mmu_req_d=1` but `mmu_req_o=0`, because the actual output is
`mmu_req_d & ~mmu_valid_i`. The fault descriptor is committed on that edge;
the registered exception is acknowledged on the next edge. On success,
`last_translation_completed` permits same-cycle ack with the AR handshake.

The successful mapping's AR is address0x80010000, len0, size5 (one32-byte
AXI beat). No skip descriptor occurs in any of these nonindexed cases.
All-off valid therefore separates missing request suppression from fault
model behavior; without a real VLDU/data oracle it is not a VRF correctness
or architectural memory-access acceptance claim.

For the failing architectural condition, the decisive raw log is:

## Future repair boundaries, not tested here

Parent's additional misalignment observation is supported by current source:
`addrgen.sv:386` checks scalar base alignment in ADDRGEN before any descriptor
or MMU request and raises LD/ST_ADDR_MISALIGNED without a predicate check.
Thus a repair only at translation1135 leaves a separate potential all-off
exception path. This is STATIC ONLY; no misaligned case was added here.

Disabling only `mmu_req_o` is insufficient: WAIT_LAST_TRANSLATION expects
last-translation completion or an exception, and consumers still need byte,
element, mask and instruction progress. A repair needs correctly owned skip
descriptors or an explicitly equivalent consumer completion path, including
VLDU/VSTU count/mask consumption. Preserve real retirement and running-ID
lifetimes; the fixture's abstract MODEL_RELEASE must not be mistaken for proof
of those contracts. The existing indexed skip path is useful precedent, not
proof a nonindexed burst can be skipped with arbitrary descriptor geometry.

## Baseline First Fault Matches the Intended Target

This was explicitly rechecked before candidate launch. The baseline
alloff_fault ELF symbol `mt_target` is 0x80000b68, instruction 0x00055c07,
the original-sequence masked `vle16.v v24,(a0),v0.t`. Its target base is
0x40001000. Before target execution the actual trace records mask byte0=0
and target leaf PTE=0. Both CSR reads and stored trap records show:

- mcause=13 at monitor cycle155821.
- mepc=0x80000b68 at cycle155833, exactly the target, not setup or a guard load.
- mtval=0x40001000 at cycle155838, exactly the protected-page target base.
- VL8, vtype8, vstart0, true S-mode MPP, expected Sv39 SATP, marker0 and PTE0.

The baseline's first software mismatch is check4, `mt_unexpected`: want0,
got1. Thus the fault's cause/PC/address match the intended reproducer location;
the exception itself is architecturally UNEXPECTED for all-off and remains a
baseline FAIL. It is not counted as a successful test simply because the
reproduction hypothesis predicted a fault.

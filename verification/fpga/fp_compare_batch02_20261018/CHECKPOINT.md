# 本次提交范围

本目录保存比较别名源布局修复的生成脚本、已验收测试源码、参考检查、原始小型DUT
日志和终验记录。功能RTL仅修改 `hardware/src/ara_dispatcher.sv`。
结论及验收边界见 `FIX_REPORT.md`，机器可读终验为 `acceptance.json`。

为避免把仿真工作目录纳入源码仓库，本次不提交ELF、simv、编译目录、大型逐指令
trace、VPD/VCD/FSDB、准备失败的中间目录。这些本机原始证据未删除；文件身份仍
保留在manifest和结果记录中。周期分析的小型events及判据随提交保留。

当前脚本使用本机归档的原始板测程序、工具链和冻结镜像，路径与哈希均明确记录，
不是独立可搬迁的工具链发行包。新机器需先取得相应归档和工具链，再使用prepare
脚本在新目录重建；缺少原始输入时应报错，不能跳过哈希检查并冒充历史验收。

本次提交不包含其他尚未整理的验证工作，不修改主线或FPGA副本，不代表新位流
已经通过原始Linux完整ELF板测。

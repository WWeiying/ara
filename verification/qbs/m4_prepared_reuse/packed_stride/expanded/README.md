# Expanded private stride acceptance

This isolated successor does not edit the original harness, the accepted private
repair, normal runtime libraries, RTL, or active QKV VCS inputs. It compiles only
a fresh test driver and explicitly links the accepted `repack.o` before the four
original normal archives. The link map must not load the archive's repack object.
The complete active VCS inventory and accepted repair/runtime manifests are
checked before and after execution. No commit or production installation is made.

## Fixed matrix

There are 65 contiguous/view pairs, N8 throughout:

- 16 K512 pairs each for Q4_K, Q6_K, Q4_0 and Q8_0.
- M1/3/4/7 with wide-M disabled, two stride/thread combinations per M.
- M8/15 with wide-M disabled and enabled, two combinations per setting.
- One additional Q6_K K1536 M15, 8-byte element stride, 16-float padding,
  wide-M enabled, two-thread pair.

The exact matrix is generated by `check.matrix()` and recorded as `matrix.json`.
Element strides are 4/8 bytes; padding is 1/3/16 floats. Thread selection alternates
across shapes so both strides occur with both one and two threads. All activation
values come from the captured Qwen2.5-1.5B `attn_norm-0` tensor [1536,15,1,1].
K512 uses each original row's first 512 values; K1536 uses complete rows. Weights
are deterministic FP32 values quantized by the real reference format quantizers.

## Construction and evidence

The dense control is a guarded VIEW. The 8-byte element-strided case uses a
VIEW with shape [1,K,M,1], followed by PERMUTE(2,0,1,3), giving [K,M,1,1]
without direct tensor metadata edits. Padding and unused interleaved elements
have finite sentinels. Scheduler callbacks check the actual shape, strides,
operation, original tensor, data pointer, and backing identity before/after each
matmul. Unexpected scheduled operations are rejected.

Every output is initially NaN, then checked finite and compared bit-for-bit.
Raw bits and round-trip FP32 decimals are recorded for every paired output.
Complete backing allocations (including padding/guards), capture, FP32 weights,
quantized weights, and entire repacked allocations are checked unchanged.

Each pair runs in a fresh exec'ed process with explicitly set flags. The host
checker reconciles per-side native calls, all execution counters, command M
histograms, dot-element totals, callbacks, planner workspace, producer block
counts where available, and guest/process exit markers. Two-thread cases must
produce two N4 chunks, not a silently serialized N8 chunk. Wide-M cases must
produce M8 (and M7 tail) native commands; setting a flag alone is insufficient.
Q8_0 activation four-row preparation uses the installed Zvfh path, which has no
M4 producer trace; source specialization, callback strides, calls and native
command accounting establish that branch. Q8_K has explicit producer traces.

`test_check.py` independently replays all four logs and rejects eleven mutations,
including a one-bit output mismatch, nonfinite output, missing calls/outputs,
wrong stride, replaced data, ignored wide flag, missing block preparation,
wrong native count, damaged integrity, and missing guest exit.

## Execution

```sh
python3 -B verification/qbs/m4_prepared_reuse/packed_stride/expanded/run.py
python3 -B verification/qbs/m4_prepared_reuse/packed_stride/expanded/test_check.py
```

Output is exclusively `verification/out/m4-stride-expanded-20261027-01` and must
not already exist. Four QEMU boots, one per weight format, each have a 300-second
limit and two guest CPUs. A guest stops on its first failed case and the runner
does not dispatch later shards. Commands, exits, images, sources and logs are
retained. This is software-functional private-object evidence only, with no
performance, whole-model, installed-runtime, RTL, or MUL_MAT_ID claim.

# FP64 除法覆盖补充

## 测试与独立检查

`vgap86_div64.c` 使用 e64/m2、tu/mu，执行 45 次带掩码除法：
五种 frm、全开/0xa5/全关三种掩码，以及 VL=32/31/1。
输入覆盖正负零、无穷、quiet/signaling NaN、除零、无效操作、
非正规数、上下溢、正负 1/3 和精确结果。预填目的组并在操作后
存回完整 32 元素，以检查掩码及尾部保持；同时核对 fflags/vstart。
预期值为固定 IEEE 位模式，而非复用 RTL 计算结果。

Spike 与旧镜像 VCS 均完成 1530 项自检，错误签名为零。
旧镜像未修改；VCS CPU 时间 134.250 秒，450 次请求/响应配对，
异常、协议错误和未完成事务均为零。

`admit_gap86_offline.py` 完成标量提交至 tohost 的对比，且没有 trap；
225 条向量提交、38580 字节严格一致，没有未知字节跳过、非位精确
结果、未完成、未退休或异常请求。已核对签名地址对应的总线字节掩码：
0x80002684 使用 0xf0，0x80002688 使用 0x0f；数据按本镜像的
unshifted RVFI store-data 规则解释。

Control-net investigation preparation:
  trace_fpga_control_net.tcl is a read-only library for an opened checkpoint.
  Source it, then call fpga_control_trace::write EXACT_NET NEW_OUTPUT_FILE.
  It reports leaf driver INIT and input nets, every load pin, and a histogram
  of primitive/pin types. Exact-name comparison preserves RTL array brackets.
  It neither changes the netlist nor requests a timing update. Existing output
  files and absent/ambiguous nets are rejected. The scheduled scoped-report
  worker remains sealed; this helper is not injected into its running script.
  Mock test PASS: /home/wangwy/fpga_runs/control_trace_mock_20261101_02.
  Vivado execution remains pending; mocks do not validate physical net content.

  RTL inspection: entry_dot_value_q and entry_aux_value_q are not reset as
  data arrays. Writes are nested under rst_ni && !clear_i, with request writes
  followed by cast completion and FP completion writes. A synthesized name
  resembling a data array can therefore identify shared write control; it is
  not enough to conclude that 2577 loads form a data-distribution network.
  Preserve write priority and clear/reset hold semantics in any future rewrite.

# Prebuilt Linux handoff artifacts

These files are the reproducible first-boot payloads generated by
`../build_linux_bringup.sh` with the repository's documented CVA6 SDK paths.
`SHA256SUMS` verifies the four files before loading them on Windows.

They are intentionally only a small initramfs and do not contain a shell,
llama.cpp, or GGUF model weights.

## 当前包含什么

| 实现 | 当前启用方式 | 保留理由与范围 |
|---|---|---|
| SIMD 整数乘法器共享 | `ARA_SHARED_SIMD_MUL` 编译宏，可选 | 保留 Booth+Dadda 版，部件省 35.72% |
| 整数 ALU 和移位器共享 | 主线源码已使用 | ALU 本体累计省 63.15% |
| VRF 返回网络精简 | 主线源码已使用 | 不含 SRAM 的对照边界省 16.93% |
| 操作数 FIFO payload 复位精简 | 主线源码已使用 | 已测完整 ALU-B 队列省 6.96%，不减容量 |
| 浮点多精度共享、紧凑流水、标签精简 | `ara_pkg::EnableSharedFma` 默认仍为 `1'b0` | ADDMUL 累计省 31.08%；不含 DIV/SQRT、CONV、NONCOMP |

共享浮点测试镜像显式启用候选，不能将候选 PPA 当作默认编译配置的实测 PPA。
不要只复制一个 `simd_fma_shared.sv` 文件：tag 契约同时涉及 `simd_fpnew.sv`、
`vmfpu.sv`，构建还应包含已登记的源码、依赖和配置。
本轮没有修改 FPGA RTL 副本或 llama.cpp；之前的
`qbs-akv-validated-20261029` 软硬件交付标签不变，也不代表已经验证本轮共享实现。

## 面积结果与整机估算

| 部件 | 原面积，平方微米 | 当前候选面积，平方微米 | 降幅 |
|---|---:|---:|---:|
| 整数乘法器组 | 32416.271510 | 20838.383837 | 35.72% |
| 整数 ALU，含移位器 | 8510.8799 | 3136.0560 | 63.15% |
| 浮点 ADDMUL | 45474.071429 | 31341.743648 | 31.08% |
| VRF 返回测试边界，不含 SRAM | 6593.327893 | 5477.303901 | 16.93% |
| 完整 ALU-B 队列 | 2405.591957 | 2238.263973 | 6.96% |

前述百分比不可相加。以四 Lane 的部件差值线性外推，前三项约省
124340.157416 平方微米，加四份 VRF 返回差值及四个已测 ALU-B 队列，合计
129473.565320 平方微米（0.12947 mm²）。没有把一个 ALU-B 队列的差值
乘以全部 36 个不同配置队列；也没有重复加入更早的 QBS 面积压缩。

历史分母取 `hardware/dc_runs/20260916_control_closure/backend/syn/ara_soc/`
`v1-dc/reports/area.rpt`（2026-09-16）：总 cell area 为 3598953.305843，
宏面积为 1983992.680664，逻辑面积为 1614960.625179 平方微米。
由此得到约 3.60% 的含宏 SoC 降幅或约 8.02% 的逻辑降幅。
这是历史分母与独立部件差值的预算估算，不是同版本全 SoC A/B 实测。
映射、跨边界优化、测试寄存器及配置变化均会影响最终收益；这些数字也不是
die area 或布局面积。实际降幅需要同库、同约束、同配置的全 SoC 对照。

## 验证证据

- ALU、VRF 返回及 FIFO 的阶段验收见各专项文档，不能将不同阶段的 62 项
  回归累加成独立指令覆盖数。
- 最新浮点三方对照：12273 周期，2492 请求，2443 完成，49 个 reset/flush
  取消。独立身份表检查重复与丢失；DIV/SQRT 遵守 VMFPU 的发射约束。
- SoftFloat 算术参考：7200 组通过，使用默认完整 tag；显式压缩 tag 的返回
  契约另由三方逐拍对照和系统测试验证，不宣称形式等价证明。
- 最新 SoC：39 程序、78 次配对运行 PASS，完成时刻和已采集周期、微内核输出、
  lane 活动相等；新增倒数估计与浮点比较测试覆盖保留 operand_a 的消费者。
- 最新部件 DC：原紧凑流水 32175.023623，压缩 tag 后 31341.743648，增量省
  2.59%。两侧原始报告和配对结果在版本化证据目录中。

本轮标签精简对上一共享版未新增周期开销。相对最初独立 FPU，共享化阶段
两个量化微内核分别增加约 0.038% / 0.048% 周期，四个量化点积周期不变；
不能据此声称对所有程序、所有配置完全无代价。

## 保留项与下一步边界

1. 保留已验证的整数共享方案；不采用已测面积更差的整数扩展共享等候选。
2. 保留浮点候选，不改变生产默认值；当前 clk_i setup 零违例但裕量接近零，
   COMBO 两条违例、hold 274 条及 infeasible-path 告警尚未闭环。
3. 不追加小范围试参或新的后台任务。下一阶段先确认集成面积与跨模块时序，
   再由结果决定是否切换默认值及 FPGA 迁移。
4. 不删除失败证据，不覆盖历史输出，不混入无关软件、TB 或依赖修改。

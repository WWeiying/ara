# 本轮软硬件优化的结束标准

## 目标与停止扩展的边界

在现有 QBS 和 AKV 硬件机制上，保留经验证有效的软件与硬件优化，完成
llama.cpp 集成、正确性和代表性性能证据闭环。充分优化不等于穷尽一切优化。
从本清单建立起，不再追加缓存变体、新指令或新硬件机制。

综合、PPA、FPGA、完整模型 RTL 吞吐和所有模型穷举不属于本轮交付。
这些限制不能被用来把切片性能写成整模型加速，或把有限测试写成普遍正确。

## 必须逐项满足的验收条件

| 编号 | 条件 | 可接受的证据 |
|---|---|---|
| E1 | 所有本轮任务进入终态，无遗留失控任务 | systemd/进程状态、独立结果文件；超时如实记失败，不自动重跑 |
| E2 | 每个候选有采纳或不采纳决定 | 原始周期、完整验收状态、失败原因；退化或证据不完整者不得进入生产路径 |
| E3 | 被采纳修改的正确性闭环 | 对应定向测试、协议检查、普通 RVV 代表性回归；已知相关错误不得悬而未决 |
| E4 | 被采纳软件修改实际接入运行时 | 共享实现、构建和运行期开关、类型/形状检查、执行前 fallback 与执行中错误传播 |
| E5 | 真实模型数值验证 | Qwen2.5 与 Qwen3 的已有配对结果，核对 token、logits、FCSR/VCSR；仅作为功能证据 |
| E6 | 性能证据口径正确 | 同任务/配置/计时范围，完整调用 ABBA；记录代表性格式和形状，未测区域不外推 |
| E7 | 结果和版本可复现 | 提交、共享源码、ELF/镜像/配置及输入哈希、原始日志、独立检查结果；外部运行时脏改动单独列明 |
| E8 | 交付明确结论 | 汇总保留与淘汰项、累计收益的正确分母、适用范围和未测范围，不重复累计收益 |

只有全部条件有证据才能关闭本轮优化。已存在且可核验的充分证据可以复用，
不因整理报告重复启动耗时仿真。若复核发现真实缺口，只补相应最小验收测试，
不借机扩展优化方向。新失败先归因，不掩盖、不降低检查标准。

## 性能与复杂度门槛

- 后续小优化至少带来约 3% 的完整算子周期改善，并具有可重复的配对趋势，
  才值得追加长仿真；这不是统计显著性的替代标准。
- 明显增加存储或控制复杂度的候选，期望至少约 5% 改善；不足则不采纳。
- 任何已测代表点的实质退化，都必须通过明确选择条件隔离，不能用平均数掩盖。
- 连续两个有依据的候选达不到收益门槛，停止该方向；保留较好的已验证实现。
- 这些是本轮工程停止规则，不反向否定此前经审查保留的低成本硬件改进。

## 固定执行顺序

1. 收齐复制 V 缓存和直接读取 V 缓存的 Q4/Q8 现有任务。超时记录不改写。
   已出现周期退化，候选保持隔离；不再启动第三种 V 缓存设计。
2. 复核 QBS retirement、M4 parallel sums、Register-PV Decode、grouped Prefill
   的已有证据与实际集成。分别区分历史测试源码与当前源码，不假定两者一致。
3. 对源码或检查范围确有变化的部分补验收；没有变化且证据充分的部分不重跑。
4. 固定交付版本并汇总完整调用周期、功能范围、未测范围及候选淘汰结论。
5. 逐条审计 E1–E8；通过后结束目标，而不是再寻找下一个小优化。

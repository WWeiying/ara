## 归因边界

既有代码生成证据表明：自定义 view 检查已证明数据对齐，但编译器未利用
该信息，额外 query 行的每个 FP32 位模式检查出现四次字节读、四次栈写和
一次栈读。候选在检查通过后显式传递对齐，变为一次 lw，仍以 memcpy
复制对象表示，避免类型双关；mask 同理保持二字节对齐。

静态路径和同 ELF 的完整周期变化共同支持这个优化方向。尚无逐阶段实测，
不能把全部节省精确分配给某一条指令或函数。候选还包含借用局部指针的
执行后清理，该成本已计入。此处 baseline 与此前规划实验的 baseline
周期不同，不跨 ELF 相减归因，也不将各次加速比相乘为端到端结果。

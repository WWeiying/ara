# 完整推理优化的当前决策与验收节点

## 1. 目标不收缩为部件提速

目标是在保留普通 RVV 的基础上，以适度的处理器资源增量降低 llama.cpp 的
Prefill 和 Decode 时间。QBS/AKV 是现有基础，不限制后续硬件方案的范围。
必要时可以增加 SRAM、存储端口、转换通路和算术资源，但必须解释它们能消除
哪一段实际执行时间。本阶段不启动综合、功耗分析或 FPGA 实验。

当前基线已经包含 QBS/AKV 及先前通过验证的软件优化。后续报告区分：普通
RVV 对照、现有加速基线、增量候选；不把过去相对普通 RVV 的总收益重新算成
新候选的增量收益。不同区域的加速比不相乘。

## 3. 当前实际执行的两个节点

### 3.1 同平台 Decode 对照

原完整 RVV worker 达到三小时限制，没有完整数值和协议 PASS，故保留为
TIMEOUT，不使用部分日志冒充完整接受。后继实验保留生产算术对象及完整 K，
仅对 caller 分组：

| 分组 | 真实输入来源 | K | N | 每份 ELF 的 ABBA native 命令 / 检查输出 |
| --- | --- | --- | --- | --- |
| 0 | Q/K/V、gate/up、最终词表投影，共六项 | 2048 | 64 | 24 / 1536 |
| 1 | FFN down | 6144 | 64 | 4 / 256 |

两份 ELF 分别在 128/256 位供给平台执行，共四路 VCS。每组包含普通生产 RVV
和 SDK 路径，计时均包含匹配的 CSR 完成和 fence。RVV 输出参考是先前
N128 exact-ELF Spike 结果的精确 N64 前缀；native 输出使用独立 QBS C 模型。
激活 payload、结果、CSR、未使用缓冲和 native 工作量都必须检查；随后运行
独立协议检查并绑定 ELF、镜像、日志和轨迹。

构建回执：
`verification/out/e2e_decode_partition_build_20261106_01/build.json`
（位于唯一验证工作树）。SHA256：
`b697cc4de84ec70cbac40c554ab41d0aeac5b220df28423447bab9e8c397e8a6`。
此实验只建立分组周期账目，不是连续七项区域或整模型测量。不得将结果按
全部输出通道机械放大，忽略固定成本和跨 tile 复用。

### 3.2 生产 GGML 的 Norm 集成

集成只改变 `ops.cpp` 中的 RMSNorm 路径和三个私有头文件。保持 FP32 平方、
按原顺序 FP64 累加、原始均值与 scale 计算，以及输出的两次 FP32 乘法舍入。
使用 VLA 的 m4 strip；保留原循环为 fallback，默认关闭，不依赖 QBS/AKV SDK。

实际生产原对象已含 ordered vector reduction，sum 主要使用 e32mf2，输出
使用 e32m1。新路径改变 strip 宽度并减少 strip 间标量种子传递，而不是首次
将 Norm 向量化。完整库保持原始编译选项，不加入 fast-math 或改变其他成员。

边界测试已检查 90 个宽度/舍入组合、30 个原地和偏移别名组合、7 个拒绝场景，
通过宿主机非 RVV fallback 和 Spike 的实际 wrapper 检查。入口先捕获 VSTART
及 FRM，再读取环境选项，防止库函数在检查前改变 VSTART；默认关闭仍有每算子
两次 CSR 读取，不称为零开销。trace 只在完整算子结束打印，不逐行打印。

`e2e_rms_ggml_library_20261106_03` 已精确复现原 ops 对象，再替换独立库中的

## 4. 下一项硬件的选择门槛

优先级由完整执行链路的可消除时间决定：

1. Decode：权重供给、请求连续性、配置与提交成本。
2. Prefill：多行权重复用、部分和驻留、格式修正与 FP 累积的供给平衡。
3. Attention：KV 访问、QK、Softmax、PV 之间的等待和中间数据传递。
4. 其余主要成本：激活量化、Norm、RoPE、SiLU、残差及布局转换；不因其不属于
   QBS/AKV 而排除，也不因容易实现而优先增加硬件。

初步筛选目标是在现有完整加速基线上争取约 1.3x 的代表性推理增量收益，新增
总资源先按约 10%--20% 预算考虑。这是选择标准，不是实测面积或性能承诺。
资源账目必须包括存储和端口，不能只比较乘法器。更大的资源投入需要明确的
收益理由；未测区域保持未知，不能由 MAC 比例替代周期比例。

供给扩宽还需单独检查外部存储约束。当前 16 MiB 平坦内存实验不等于完整模型
经 DDR 读取权重：内部入口扩为 256 位并不自动增加 DDR 的可用带宽。如果模型
已受外部带宽限制，应优先核查多行权重复用、事务效率和激活/部分和驻留，而非
由内部总线实验直接预测 token/s。后续周期模型须列出外部有效带宽及敏感性，
不能把 SRAM 响应条件隐含为端侧部署条件。

达到局部实验 PASS 不是本目标完成。还需将实测收益对应到完整调用和真实
模型工作量，检查多形状适用性和普通 RVV/fallback，并决定保留或拒绝候选。

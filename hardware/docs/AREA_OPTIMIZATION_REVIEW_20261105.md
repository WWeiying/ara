# Lane 面积优化汇总与后续选择

## 当前结论

当前已取得的主要收益来自多精度整数乘法器、整数 ALU/移位器共享，以及
浮点 ADDMUL 共享和流水存储压缩。保留已验证实现，不继续盲目重写乘法阵列。
下一项优先审查 ADDMUL 专用事务标签，随后再依据映射面积决定是否扩展到
其他流水数据存储。本文只整理证据和静态方案，不新增 RTL 试验或综合任务。

后续进展：ADDMUL 专用 tag 候选已实施并通过部件检查，详见
[tag 精简与验收](FMA_TAG_COMPACTION_20261105.md)。下表仍为已完成综合的
保留版数字，不能把新候选的预计收益计入其中。

工作目录为 `ara_dsa`，最新紧凑 FMA 实现提交 `cad2e4950`；仿真与综合
证据统一在 `ara_dsa_signoff_integration/verification/out/`。
整数共享乘法器仍需 `ARA_SHARED_SIMD_MUL` 开关，浮点共享仍默认关闭。
ALU、VRF 返回网络和操作数 FIFO 的已接受修改已在主线源码中。
未迁移本轮修改到 FPGA，也没有本轮全 SoC 映射结果。

## 已完成的面积优化

下表是各自同条件部件对照，边界不同，百分比不能相加。

| 部件与边界 | 原面积，平方微米 | 保留版面积，平方微米 | 降幅 | 功能与性能证据 |
|---|---:|---:|---:|---|
| SIMD 整数乘法器组 | 32,416.271510 | 20,838.383837 | 35.72% | Booth+Dadda 保留版；部件及限定 SoC 周期验收 |
| 整数 ALU 本体，含共享移位器 | 8,510.8799 | 3,136.0560 | 63.15% | 算术共享与移位共享分阶段通过；62 项 SoC 验收 |
| VRF 返回网络，含相同测试寄存器边界，不含 SRAM | 6,593.327893 | 5,477.303901 | 16.93% | 局部三方核对、62 项 SoC、逐拍路由对照 |
| 完整 ALU-B 操作数队列 | 2,405.591957 | 2,238.263973 | 6.96% | FIFO 深度/复位/flush 检查；62 项 SoC、36 个队列逐拍对照 |
| 单 lane 浮点 ADDMUL | 45,474.071429 | 32,175.023623 | 29.25% | 独立 SoftFloat、旧版逐周期核对、31 程序各两次 SoC 验收 |

ALU 本体与包装模块不是同一面积口径；FIFO 数据不可直接乘以所有队列数，
因为不同队列的深度与功能配置不同。FMA 不包含 DIV/SQRT、CONV 和整个 VMFPU。
若要给出总芯片降幅，必须有同配置、同库、同约束的新旧全芯片综合；当前
不能将上表的局部差值直接当作已实现的 SoC 减少量。

详细来源：

- [整数乘法器](SHARED_SIMD_MULTIPLIER.md)：保留 Booth 版，不采用更差的后续候选。
- [整数 ALU](SHARED_SIMD_ALU.md) 与 [共享移位器](SHARED_SIMD_ALU_SHIFT.md)。
- [VRF 返回网络](VRF_RETURN_OPTIMIZATION_20261104.md)。
- [操作数 FIFO](OPERAND_FIFO_RESET_OPTIMIZATION_20261104.md)。

## 浮点本轮到底减少了什么

旧共享版在每个子通路放两级输入、两级中间结果和一级输出寄存器；本轮改为
各一级输入、中间结果、输出，再将格式拼接后的结果统一延迟两级。
四个 FP16、两个 FP32、一个 FP64 的 SIMD 空间并行能力没有改变。

总面积从 35,576.687576 降至 32,175.023623 平方微米。组合逻辑增加
250.151997，时序单元减少 3,651.815950，净减少 3,401.663953。
这验证了“缩短宽中间值的存储时间”比继续微调部分积逻辑更值得优先做。

62 次 SoC 运行通过，与上一共享版本的计时和输出记录完全一致。相对最初
独立 FPU，两个量化微内核仍有 +0.038% / +0.048% 的周期变化，四个量化点积
周期不变；不能把本轮无新增退化写成整个共享改造对所有软件都零开销。

## 下一项：按运算组精简 tag

### 静态依据

`vmfpu.sv` 的综合用 `vfpu_tag_t` 包含：

| 字段 | 位数 | 消费位置 | ADDMUL 是否能直接删除 |
|---|---:|---|---|
| operand_a | 64 | VFREC7/VFRSQRT7 使用原始操作数；比较路径使用逐元素 NV 信息 | 可研究仅在 ADDMUL 内不传递 |
| flag_mask | 8 | 返回异常标志的掩码处理 | 本轮保留，不混入第二项精简 |
| control | 8 | 掩码及归约中性元素标记 | 保留 |
| debug_id / debug_ara_op | 仅仿真存在 | 请求与返回顺序断言 | 保留检查能力，不能静默关闭 |

审查覆盖 `vfpu_tag_in` 构造、`operand_a_delay`、比较结果 bit 2、
`vfpu_ex_flag_fn` 掩码及归约 control 消费逻辑。ADDMUL 的结果不依赖返回的
operand_a，但不能在共享的全 FPU 接口上删除该字段，否则估计指令与比较
异常会出错。不能把现有 `simd_fma_shared` 泛型 TagType 当作可任意丢弃的
数据：独立部件的契约仍然是原样传递调用者 tag。

### 推荐边界

在明确理解 VMFPU tag 类型的适配层，为 ADDMUL 选择紧凑 tag，其余 opgroup
继续传完整 tag。返回适配层只为已证明不被 ADDMUL 消费的字段补定义值。
不要改 FPnew 算术依赖，也不要用当前位置的请求控制去解释较早返回的事务。
保留原实现为对照，保证 reset、flush、背压和多精度混合时事务身份一致。

粗略规模是 64 位乘以五级，即 320 个数据存储位，而不是四个子通路各乘一次。
旧映射已经裁掉其他子通路未用的 tag 输出。当前公共输出的 tag 仍有存储成本，
但全 SoC 上综合器可能进一步传播无用信息；因此部件节省不能预先等同于
VMFPU 或 SoC 的新增收益。须同时检查集成边界是否已经消除了这些位。
此前单元面积代理约为每 lane 968 平方微米，只用于筛选，绝不是本轮实测收益。

### 验收方式与停止条件

1. 先确认集成网表中的实际 tag 存储数量；若已经大部分裁掉，不继续此项。
2. 只修改 ADDMUL 的 tag 适配，保持其他字段及算术流水不变。
3. 部件逐拍对照有效结果、fflags、必要 tag、ready/valid/busy；补比较 NV、
   reciprocal/rsqrt、归约、混合 opgroup 的系统测试，不只重复乘加数值测试。
4. 检查程序周期和真实微内核数据，再做一次同条件部件面积对照。
5. 若系统可省面积很小或新增 mux/控制抵消收益，保留当前版本，不连续试参。

## 再往后的优先级

| 顺序 | 方向 | 取舍 |
|---|---|---|
| 1 | ADDMUL 专用 tag | 语义边界清楚；收益预计小于本轮流水压缩，先确认集成后仍有冗余 |
| 2 | 有效位保护下的局部 payload 复位精简 | 只选占比较高且能证明先写后读的存储；不全局删除 FPnew reset |
| 3 | 共享后的控制/返回时序 | 先看真实 VMFPU 边界 COMBO、hold 与背压路径；不以减少吞吐换面积 |
| 4 | DIV/SQRT、CONV、NONCOMP 的面积普查 | 现有前两组已采用 MERGED；需先证明剩余重复，不能再算一遍共享收益 |
| 暂缓 | FP64 分区乘法阵列、跨 lane 共用执行器 | 前者验证复杂、已有 DW 融合；后者影响并行度与结果路由，当前不优先 |
| 不采用 | 已测更差的整数扩展共享等候选 | 保留失败证据，不把未采用版本算进当前收益 |

本轮不扩展到 QBS/AKV 存储容量，不缩减 VLEN、队列容量或支持的精度。
如果希望再获得显著的整芯片降幅，必须先有当前集成版的层级面积占比；
单靠继续打磨约 3,136 平方微米的整数 ALU，很难保证再有同等级收益。

## 当前尚未完成的验收

- 部件 COMBO 两条 setup 违例仍在，最差 -0.36 ns；hold 527 条，最差 -0.08 ns。
- clk_i setup 零违例仅在当前 1 ns / 0.15 ns 条件下成立，裕量约 0.027 ps。
- 需要解释 infeasible-path 告警、补齐实际 I/O 的 min delay，并在集成上下文
  检查真实跨模块路径；不通过放宽约束或无依据豁免来宣称时序完成。
- 没有本轮全 SoC 面积或布局布线结果，没有新的 FPGA 验收。

目前结论是“功能和限定性能验收已通过、部件面积收益明确的保留候选”，
而不是全部配置、所有程序和物理实现均完成签核。
